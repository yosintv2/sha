About cSHAKE256 File Hash Calculator

cSHAKE256 is the 256-bit security variant of cSHAKE from NIST SP 800-185. It uses the same Keccak sponge as SHAKE256 but accepts domain separation parameters making it ideal for protocols that require multiple independent hash outputs from a single primitive.
