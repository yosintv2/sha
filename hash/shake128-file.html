Frequently Asked Questions

About SHAKE128 File Hash Calculator

Compute the SHAKE128 XOF checksum of any file in your browser. SHAKE128 is an extendable output function from NIST FIPS 202, providing 128-bit security with variable output length. Configure the output bit count in Settings. All processing is local.
