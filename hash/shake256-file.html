About SHAKE256 File Hash Calculator

Compute the SHAKE256 XOF checksum of any file in your browser. SHAKE256 is an extendable output function from NIST FIPS 202, providing 256-bit security with variable output length. Used in NIST post-quantum cryptography standards. Configure the output bit count in Settings. All processing is local.
