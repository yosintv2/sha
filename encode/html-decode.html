Frequently Asked Questions

Does this handle all HTML entities?
Yes. By setting innerHTML on a DOM element, the browser's own HTML parser decodes all named entities (&amp;, &copy;, etc.) and numeric entities (both decimal &#169; and hex &#xA9;).
